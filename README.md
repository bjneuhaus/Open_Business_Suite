# Sovereign Business Suite

Proof of Concept für eine modular verwaltete Open-Source-Unternehmensplattform.

Der erste PoC läuft auf einer einzelnen Linux-VM mit Podman und einer Python/Flask-basierten Verwaltungsoberfläche. Erste Referenzanwendung ist OpenCloud.
