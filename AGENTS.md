# Instructions for AI Agents

Diese Datei ist für alle KI-Agenten verbindlich.

## Vor jeder Änderung lesen
1. `PROJECT.md`
2. `ROADMAP.md`
3. `WORKFLOW.md`
4. `CODE_STYLE.md`
5. `DEFINITION_OF_DONE.md`

## Arbeitsauftrag
Bearbeite ausschließlich den Roadmap-Punkt, den der Benutzer ausdrücklich freigegeben hat.

Ist kein Punkt eindeutig freigegeben: **nicht implementieren**, sondern nachfragen.

## Prioritäten
1. Usability
2. Simplicity
3. Maintainability
4. Security
5. Functionality
6. Technical Elegance

## Git
- niemals direkt auf `main`
- pro Roadmap-Punkt eigener Branch
- kleine nachvollziehbare Commits
- keine eigenständigen Merges
- nach PR-Vorbereitung stoppen

## Dokumentation
Dokumentation ist Teil der Implementierung.

## Scope
Änderungen außerhalb des aktuellen Scopes nicht ungefragt implementieren.

## Architektur
Bei grundlegenden Entscheidungen zuerst Vorschlag und Begründung liefern und auf Freigabe warten.
